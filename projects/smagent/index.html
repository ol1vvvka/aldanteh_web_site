{ Мобильная торговля }

SmAgent.

От плана посещений до заявки клиента.
Рабочий день торгового представителя — в одном приложении.

SmAgent помогает торговым представителям выполнять задачи на точках, а супервайзерам — видеть маршрут и результаты команды. Приложение работает на Android и iOS и сохраняет данные, когда нет связи.

{ 01 / Начало дня }

Рабочий день —
перед глазами.

На главном экране собраны заявки за сегодня, сумма заказов и количество пройденных точек маршрута. Рядом — информация о долгах клиентов и времени последнего обмена с 1С.

Создать заказ, анкету или возврат можно из блока быстрых действий.

{ 02 / Маршрут }

От торговой точки
к следующему визиту.

Переключайтесь между маршрутом на выбранную дату и общим списком клиентов. Поиск по названию или адресу помогает найти нужную точку, а карта — увидеть её расположение.

В карточке клиента доступны контактные данные и переход к созданию заявки, анкеты или возврата. Документы и карта открываются рядом со списком.

{ 03 / Ассортимент }

Подобрать товар.
Проверить остатки.

Каталог объединяет фотографии, цены и доступное количество. Товары можно искать по названию, артикулу или коду, просматривать списком либо плиткой.

Фильтры помогают выбрать товары в наличии, ранее купленные позиции и предложения по акциям. В карточке товара видны характеристики, остатки по складам и партиям, сроки годности.

{ 04 / Заявка }

Собрать заказ
прямо у клиента.

При оформлении заявки выбираются фирма, склад и клиент. Представитель добавляет товары, меняет количество и сразу видит сумму по позиции и общий итог.

Фильтр «Добавлено в заказ» помогает проверить состав заявки. Сохранённые документы доступны в отдельном разделе вместе со статусом и данными заказа.

{ 05 / Показатели }

Понимать результат.
Видеть следующий шаг.

Экран KPI показывает план, факт, процент выполнения, заказанное и прогноз. Данные раскрываются по направлениям, группам и категориям товаров.

В блоке мотивации видны условия по отгрузке, активной клиентской базе, просроченной задолженности и прямым контрактам. Представитель может сравнить текущий результат с установленными ступенями.

{ Связь с учётной системой }

Работа продолжается
и без интернета.

При отсутствии связи данные сохраняются на устройстве и синхронизируются после восстановления подключения. Время обмена и обновления остатков отображается на главном экране.

Для руководителя по данным приложения формируется отчётность о посещениях, маршрутах, времени работы и выполненных задачах. Состав отчётов и правила обмена обсуждаем при внедрении.

{ Следующий шаг }

Начнём с ваших процессов.

Чтобы обсудить внедрение предметно, разберём, как команда работает сейчас и какие задачи нужно перенести в приложение.

  • Количество представителей, территории и графики посещений.
  • Организации, склады и правила оформления клиентских заявок.
  • Нужные анкеты, чек-листы и отчётность руководителя.
  • Учётная система и требования к обмену данными.
