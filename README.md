# АЛДАН ТЕХ — корпоративный сайт

Сайт ИТ-компании «АЛДАН ТЕХ»: разработка и сопровождение 1С, мобильные приложения, интеграции и собственные продукты SmAgent и «Маркетинг в 1С».

Статический многостраничный сайт на HTML, CSS и JavaScript. Сборщик, npm и серверная часть не требуются.

## Возможности

- 11 страниц: главная, компания, экспертиза, контакты, услуги и направления, каталог и две отдельные страницы продуктов.
- Светлая и тёмная темы, адаптивная навигация, шрифт Manrope и фирменный синий.
- Реальные скриншоты продуктов с увеличением внутри страницы.
- Предварительный расчёт стоимости работ по 1С.
- Контакты, реквизиты и неподвижная Яндекс-карта с фирменной меткой.
- Анимация облака на WebGL и независимые интерактивные подписи. При недоступности WebGL отображается SVG.
- Учёт настройки уменьшения движения; перебор символов только в главных заголовках.

## Локальный запуск

Нужен Python 3 либо любой другой статический HTTP-сервер.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Откройте [локальный сайт](http://127.0.0.1:4173/). Двойной щелчок по `index.html` не подходит: адреса ресурсов и страниц начинаются с `/`.

## Структура

| Путь | Содержание |
| --- | --- |
| `index.html` | Главная страница |
| `about/`, `expertise/`, `contacts/` | Компания, экспертиза, контакты |
| `services/` | Услуги, направления и калькулятор |
| `projects/` | Каталог, SmAgent и маркетинг в 1С |
| `assets/css/` | Общие стили, внутренние страницы и продукты |
| `assets/js/` | Навигация, темы, эффекты, просмотр изображений, карта и расчёт |
| `assets/images/`, `assets/icons/` | Только используемые изображения и значки |
| `scripts/package_site.py` | Проверка локальных ссылок и создание ZIP для хостинга |
| `docs/` | Редактирование и размещение на NetAngels |
| `robots.txt`, `sitemap.xml` | Индексация страниц |

## Архив для NetAngels

```powershell
python scripts/package_site.py
```

Результат — `dist/aldanteh-netangels.zip`. В корне архива находится `index.html`; служебные файлы, документация и Git в него не входят. Инструкция: [размещение на NetAngels](docs/deployment.md).

## Что важно знать

- Форма связи и калькулятор подготавливают письмо через `mailto:`. Отправку выполняет посетитель в своей почтовой программе. Серверной отправки нет.
- Калькулятор даёт предварительную оценку. Ставки перенесены с действующего сайта; актуальность цен нужно подтвердить перед публикацией.
- Яндекс-карты требуют доступа к внешнему API. Браузерный ключ находится в разметке контактов и по своей природе виден посетителям; допустимые домены и лимиты настраиваются в кабинете Яндекса. При ошибке API предусмотрен встроенный виджет.
- Пути и canonical рассчитаны на размещение в корне `aldanteh.ru`, а не в `/v03/` или другой подпапке.
- Скриншоты SmAgent предоставлены с демонстрационными данными и разрешены владельцем для сайта и репозитория.
- Пуш в GitHub не публикует файлы на рабочем хостинге.
