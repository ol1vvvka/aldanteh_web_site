# Редактирование сайта

Страницы редактируются напрямую в HTML. Генератора страниц и сборщика нет. Шапка и подвал повторяются в 11 HTML-файлах: общие изменения нужно вносить во все страницы.

## Стили

- `assets/css/main.css` — переменные двух тем, общий макет, навигация, главная, формы и адаптация.
- `assets/css/components.css` — хлебные крошки и базовые блоки внутренних страниц.
- `assets/css/products.css` — страницы продуктов, галереи и окно увеличения изображений.

Основной шрифт — Manrope (Google Fonts). Базовый фирменный цвет — `#047bdc`; в тёмной теме ссылки светлее. Изменяйте цветовые переменные обеих тем, а не только светлой. Фон светлой темы — холодный `#eef2f5` с мягким голубым свечением.

## Скрипты

| Файл | Назначение |
| --- | --- |
| `theme.js` | Выбор темы до отрисовки страницы |
| `main.js` | Меню, темы, вкладки и подготовка письма |
| `motion.js` | Эффекты прокрутки, параллакс, перебор символов в H1 |
| `fluid.js` | Облако WebGL и отталкивание независимых подписей |
| `contact-map.js` | Сетка и свечение блока связи |
| `office-map.js` | Неподвижная карта офиса с фирменным пином |
| `pricing.js` | Предварительная оценка работ по 1С |
| `image-viewer.js` | Увеличение скриншотов, Escape и возврат фокуса |

WebGL работает до 30 кадров в секунду, останавливается вне экрана и в скрытой вкладке. При уменьшении движения отображается статический кадр. `system-core.svg` нужен как резервное изображение и не является лишним файлом.

## Контент

Описание продуктов основано на материалах действующего сайта. Актуальные кадры SmAgent находятся в `assets/images/projects/smagent/`; данные демонстрационные. Скриншоты маркетинга — `111.png`, `444.png`, `555.png`.

Форма открывает письмо на info@aldanteh.ru. Калькулятор использует 3 600 ₽/час для middle и 4 200 ₽/час для senior, от 1 до 160 целых часов. Источник прайса — действующий сайт, дата исходного прайса 01.07.2025. Уточняйте ставки перед размещением.

Полные реквизиты находятся в `contacts/index.html`, основные контакты — также в подвалах. Клиентский ключ карты задаётся в `data-api-key`; не заменяйте его серверными секретами.

## Проверка изменений

1. Запустите сайт через HTTP, как указано в README.
2. Проверьте изменённые страницы в обеих темах и на узком экране.
3. Проверьте меню, переходы, форму, калькулятор и увеличение изображений по мере затрагивания этих функций.
4. Выполните `python scripts/package_site.py`: скрипт проверит локальные пути, якоря и карту сайта, затем создаст архив.

При изменении адресов обновляйте ссылки, canonical и `sitemap.xml`. При обновлении CSS и JS меняйте параметр `?v=` у подключения, чтобы браузер не использовал старую копию.
