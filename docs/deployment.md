# Размещение на NetAngels

Сайт статический: достаточно хостинга с поддержкой HTML, CSS и JavaScript. Python и Node.js на сервере не нужны.

## Подготовка

Из корня проекта выполните:

```powershell
py -3 scripts/package_site.py
```

Архив `aldanteh-netangels.zip` появится в корне проекта (рядом с `index.html`). Копия также пишется в `dist/`. Внутри ZIP `index.html` лежит в корне.

## Размещение

1. Сохраните резервную копию текущих файлов сайта и базы WordPress, если меняете действующий сайт.
2. В панели NetAngels найдите каталог документов именно нужного домена. Его фактический путь определяется настройками хостинга.
3. Загрузите и распакуйте архив в нужный каталог: рядом должны оказаться `index.html`, `assets/`, `.htaccess`, `projects/`, `services/` и остальные разделы. Можно размещать в корне домена или в подпапке (`v05/`, `new/` и т.п.). Не создавайте лишнюю обёртку вокруг содержимого архива.
4. При замене WordPress проверьте порядок индексных файлов и старые правила перенаправления. Старый `index.php` или rewrite-правила не должны перехватывать запросы к новому сайту. Сохраните старую конфигурацию перед изменением.
5. Убедитесь, что HTTPS настроен для домена, а каталоги открываются через свои `index.html`.
6. Проверьте главную, страницы продуктов, `/services/#pricing`, `/contacts/`, обе темы и мобильное меню.
7. Проверьте разрешённый домен для браузерного ключа Яндекс Карт. Также проверьте подготовку письма и увеличение скриншотов.

## Ограничения размещения

- Внутренние ссылки и ресурсы относительные (`assets/...`, `../assets/...`) — так же открываются локально через `file://`. `robots.txt`, canonical и sitemap указывают на `https://aldanteh.ru/` — для другого домена SEO-адреса нужно поправить отдельно.
- Не загружайте `.git`, локальные настройки и документы разработки в каталог сайта.
- Старые URL WordPress следует сопоставить с новыми страницами и настроить постоянные перенаправления на стороне хостинга. Этот архив не меняет серверную конфигурацию.
- Форма связи использует почтовую программу посетителя; SMTP или обработчика отправки в архиве нет.
