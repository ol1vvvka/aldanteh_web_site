О нас

Разбираемся в процессах. Связываем системы.

АЛДАН ТЕХ — команда разработки из Екатеринбурга. Помогаем торговым и производственным компаниям автоматизировать ежедневную работу.

Дорабатываем 1С, создаём мобильные приложения и настраиваем обмен данными. Начинаем с конкретной задачи и учитываем системы, которые у вас уже работают.

Работаем с торговлей и FMCG, пищевым производством, складом и логистикой.

{ 01 }

Сначала слушаем

Обсуждаем задачу, изучаем процессы и текущую систему. Определяем, что должно измениться.

{ 02 }

Договариваемся о решении

Согласуем объём, этапы и стоимость. Фиксируем, какой результат вы получите и как будем его проверять.

{ 03 }

Разрабатываем и показываем

Делимся промежуточными результатами. Проверяем решение на ваших сценариях и данных.
